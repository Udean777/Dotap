Privacy Policy

Dotap for Android · Last updated: November 21, 2026

Dotap is an Android utility app that places a floating dot on your screen so you can trigger navigation and system actions with taps, swipes, or a long press.

Data collection

Dotap does not collect, store, or share personal data. The app contains no analytics, no advertising SDKs, and no crash-reporting services that send data off your device.

Network access

Dotap does not request the INTERNET permission. All features run locally on your device.

AccessibilityService API

Dotap uses Android's AccessibilityService API for two purposes only:

  • Displaying the floating dot overlay on top of other apps.
  • Running the global system actions you assign to dot gestures, such as taking a screenshot, going back, opening home or recents, or opening the quick panel.

Dotap does not read screen content, inspect window hierarchies, log keystrokes, or collect text from any app.

Local storage

Your gesture mappings, dot appearance settings, theme, language, and dot position are saved locally on your device using AndroidX DataStore. Uninstalling the app removes all saved preferences.

Changes to this policy

If this policy changes in a future update, the updated version will be published on this page with a revised date.

Contact

Questions about this policy can be opened as an issue in the Dotap GitHub repository.

Dotap adalah aplikasi utilitas Android yang menampilkan titik mengambang di layar untuk menjalankan aksi navigasi dan sistem lewat ketukan, geseran, atau tekan lama.

Pengumpulan data

Dotap tidak mengumpulkan, menyimpan, atau membagikan data pribadi. Aplikasi ini tidak memakai analitik, SDK iklan, maupun layanan pelaporan error yang mengirim data keluar dari perangkat Anda.

Akses jaringan

Dotap tidak meminta izin INTERNET. Seluruh fitur berjalan secara lokal di perangkat Anda.

AccessibilityService API

Dotap menggunakan AccessibilityService API Android hanya untuk dua hal:

  • Menampilkan titik mengambang di atas aplikasi lain.
  • Menjalankan aksi sistem global yang Anda pasang ke gestur titik, seperti mengambil tangkapan layar, kembali, membuka beranda atau aplikasi terbaru, atau membuka panel cepat.

Dotap tidak membaca isi layar, memeriksa struktur tampilan aplikasi lain, mencatat ketikan, atau mengambil teks dari aplikasi mana pun.

Penyimpanan lokal

Pengaturan gestur, tampilan titik, tema, bahasa, dan posisi titik disimpan secara lokal di perangkat menggunakan AndroidX DataStore. Menghapus aplikasi akan menghapus seluruh pengaturan tersebut.
